## 📂 Selected Projects

### [Brent](https://github.com/bluntschli1821/brentw)

A modern real-estate discovery platform for browsing homes and workspaces. Built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, and Firebase.

### [Movie Munch — Web](https://github.com/bluntschli1821/movie-munch-next)

A movie-discovery web app for browsing popular films, searching titles, viewing detailed movie information, and exploring community-driven trends.

Built with Next.js, TypeScript, Tailwind CSS, Appwrite, and the TMDB API.

### [Movie Munch — Mobile](https://github.com/bluntschli1821/MovieMunch)

The mobile version of Movie Munch, designed as a cross-platform movie discovery experience for Android, iOS, and the web.

Built with React Native, Expo, Expo Router, NativeWind, React Native Appwrite, and TypeScript.

### [Danilo Maritime](https://github.com/bluntschli1821/danilomaritime)

A responsive maritime services and marketing website with clear user journeys, polished presentation, and conversion-focused calls to action.

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

### [PayCycle](https://github.com/bluntschli1821/PayCycle)

A cross-platform mobile application built with React Native and Expo, with authentication, secure local storage, navigation, styling, and product analytics integrations.
